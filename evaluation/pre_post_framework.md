# Optional pre/post evaluation framework

This is a future-adoption framework; it is not evidence of learning gains in
the present paper.

Use parallel pre/post forms (10-15 minutes): four multiple-choice items on
depletion formation, field direction, built-in potential, and charge
neutrality; three constructed responses on asymmetry, model assumptions, and
`delta_num`; and one transfer item with an unfamiliar doping ratio.

Score each constructed response 0 (incorrect/no reasoning), 1 (partly correct),
or 2 (correct claim with physical justification). Report paired mean or median
change with a confidence interval and a standardised within-group effect size.
If a comparison class exists, compare post-test scores with pre-test score as a
covariate. Preserve anonymised scoring records and use two independent raters
for a rubric-reliability check when feasible.
