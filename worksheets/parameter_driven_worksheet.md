# Parameter-driven worksheet

All code is supplied in `pn_junction_teaching_module.ipynb`.

1. Run the baseline case.
2. Change `Na` by factors 0.1 and 10; record `xp`, `xn`, and peak `|E|`.
3. Verify `Na*xp=Nd*xn`.
4. Change `delta_fraction`; identify numerical, not physical, changes.
5. Before running a new asymmetric case, predict which side is wider and why.
